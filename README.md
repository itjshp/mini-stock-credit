# Khaikhong v2.3.9

เวอร์ชันนี้แก้บัค PIN Lock ที่ขึ้นหน้าล็อกทั้งที่ยังไม่ได้ตั้ง PIN

## สิ่งที่แก้

1. ถ้ายังไม่เคยตั้ง PIN จริง ระบบจะไม่ล็อกหน้าจอ
   - ตรวจว่าต้องมี enabled = true
   - และต้องมี pinHash ที่เป็น SHA-256 ถูกต้อง 64 ตัวอักษร
   - ถ้าค่า PIN ผิดรูปแบบ ระบบจะปิด PIN ให้เอง

2. ปุ่ม ลืม PIN ใช้งานได้แน่นขึ้น
   - Reset เฉพาะ PIN
   - ไม่ลบข้อมูลสินค้า/ลูกค้า/บิล
   - ออกจากหน้าล็อกทันทีหลัง Reset

3. เพิ่มวิธีช่วยฉุกเฉินผ่าน URL
   - ถ้าติดหน้าล็อก ให้เติมท้ายลิงก์ว่า:
     ?resetPin=1
   - แล้วกด Enter
   - ระบบจะ Reset เฉพาะ PIN ให้

ตัวอย่าง:
https://itjshp.github.io/xxxx/?resetPin=1

## วิธีอัปเดตกรณีกำลังติดหน้าล็อก

1. ไปที่ GitHub แล้วอัปโหลด v2.3.9 ทับไฟล์เดิม
2. Commit changes
3. รอ GitHub Pages deploy 1-3 นาที
4. กลับมาหน้าเว็บแล้วกด Ctrl+F5
5. ถ้ายังติดล็อก ให้เติม `?resetPin=1` ต่อท้าย URL แล้วกด Enter

## วิธีทดสอบ

1. เปิดเว็บหลังอัปเดต ถ้ายังไม่ได้ตั้ง PIN ต้องไม่ขึ้นหน้าล็อก
2. ไปที่ เพิ่มเติม > ระบบ / ตั้งค่า / ความปลอดภัย > ความปลอดภัย
3. ตั้ง PIN ใหม่
4. กด ล็อกแอปตอนนี้
5. ใส่ PIN เพื่อปลดล็อก
6. กด ลืม PIN แล้ว Reset ได้
