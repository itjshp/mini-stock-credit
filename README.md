# Mini Stock Credit PWA

เวอร์ชัน v0.3

เพิ่มจาก v0.2:
- แก้ไขรายการซื้อเข้าย้อนหลัง
- แก้ไขรายการขายย้อนหลัง
- แก้ไขรายการรับชำระย้อนหลัง
- มีปุ่มยกเลิกโหมดแก้ไข
- ปรับ UI รายการล่าสุดให้อ่านง่ายขึ้น มีปุ่มแก้ไข/ลบชัดเจน
- คำนวณสต็อก ต้นทุนเฉลี่ย กำไร และลูกหนี้ใหม่อัตโนมัติหลังแก้ไข/ลบ

## วิธีอัปเดตบน GitHub Pages

1. แตกไฟล์ zip
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ทับไฟล์เดิมใน GitHub Repository
3. Commit changes
4. รอ GitHub Pages deploy 1-3 นาที
5. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิดแอปใหม่ เพราะ PWA มี cache

## หมายเหตุสำคัญ

ข้อมูลจริงเก็บใน Browser/เครื่องที่ใช้งานด้วย IndexedDB ไม่ได้เก็บบน GitHub
ควร Export Backup เป็นประจำ โดยเฉพาะก่อนล้างเครื่อง เปลี่ยนมือถือ หรือล้าง Browser
