# Khaikhong v2.3.7

เวอร์ชันนี้ปรับหน้า เพิ่มเติม ให้ไม่รกและใช้งานง่ายขึ้น

## สิ่งที่ปรับ

1. หน้า เพิ่มเติม แบบใหม่
   - ไม่แสดงเมนูทั้งหมดพร้อมกันแล้ว
   - แสดงเฉพาะ เมนูด่วน และ หมวดเมนู

2. หมวดเมนู
   - ขาย / เงิน / ลูกหนี้
   - สต็อก / ต้นทุน
   - ระบบ / ตั้งค่า / ความปลอดภัย
   - เมนูทั้งหมด

3. กดเข้าไปดูเมนูย่อย
   - เมื่อกดหมวด ระบบจะแสดงเฉพาะเมนูในหมวดนั้น
   - มีปุ่ม กลับหมวดเมนู

4. ค้นหาเมนูแบบไม่รก
   - พิมพ์คำค้นหาแล้วแสดงเฉพาะผลค้นหา
   - ไม่โชว์เมนูทุกหมวดพร้อมกัน

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำให้ทดสอบ

- เปิดหน้า เพิ่มเติม
- กดหมวด ขาย/เงิน
- กดหมวด สต็อก
- กดหมวด ระบบ
- ใช้ช่องค้นหา เช่น บิล, FIFO, Backup
