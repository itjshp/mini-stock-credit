# Khaikhong PWA

เวอร์ชัน v1.1 — Fast Search + Today/Month Summary

สิ่งที่เพิ่ม/ปรับ:
- เพิ่มค้นหาในหน้า `สินค้า`
- เพิ่มค้นหาในหน้า `ลูกค้า`
- หน้า `สรุป` เพิ่มยอดขายวันนี้ / กำไรวันนี้ / ยอดขายเดือนนี้ / Backup ล่าสุด
- หน้า `รายงาน` เพิ่มปุ่มกรองเร็ว: วันนี้ / เดือนนี้
- หน้า `ขายของ` ค้นหาสินค้าแล้วกด Enter เพื่อเลือกสินค้ารายการแรกได้
- ยังคงคู่มือใช้งานจาก v1.0
- ยังปิด Upgrade / Demo / Pro ไว้ก่อน เพื่อโฟกัสความนิ่งและใช้งานจริง

## วิธีอัปเดต GitHub Pages

1. Export Backup JSON จากแอปเดิมก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่ เพราะมี cache

## แนวทางทดสอบ

- เพิ่มสินค้า 3-5 รายการ
- ทดสอบค้นหาสินค้าและลูกค้า
- ขายสด/เครดิต
- ดูสรุปวันนี้/เดือนนี้
- Export Backup และ Import กลับมาทดสอบ
