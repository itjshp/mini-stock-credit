# Khaikhong v2.3.8

เวอร์ชันนี้เพิ่ม PIN Lock และ Backup Restore Safety

## สิ่งที่เพิ่ม

### 1. PIN Lock
อยู่ที่ เพิ่มเติม > ระบบ / ตั้งค่า / ความปลอดภัย > ความปลอดภัย

ฟีเจอร์:
- ตั้ง PIN 4-6 หลัก
- ล็อกแอปตอนนี้
- ล็อกอัตโนมัติเมื่อเปิดแอป
- ปิดใช้ PIN ด้วยการใส่ PIN เดิม
- กรณีลืม PIN สามารถ Reset เฉพาะ PIN บนเครื่องนี้ได้

หมายเหตุ:
PIN Lock เป็นการป้องกันการเปิดดูข้อมูลแบบง่ายบนเครื่องนี้ ไม่ใช่ระบบ Login Cloud

### 2. Backup Restore Safety
ก่อน Restore Backup ระบบจะแสดงข้อมูลในไฟล์ก่อน เช่น:
- เวอร์ชัน
- วันที่ Export
- จำนวนสินค้า
- จำนวนลูกค้า
- จำนวนบิล
- จำนวนรายการรับเงิน
- FIFO lots
- ปิดรอบ

และต้องพิมพ์คำว่า RESTORE เพื่อยืนยันก่อนนำเข้าข้อมูล

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำให้ทดสอบ

1. ไปที่ เพิ่มเติม > ระบบ / ตั้งค่า / ความปลอดภัย
2. กด ความปลอดภัย
3. ตั้ง PIN 4-6 หลัก
4. กด ล็อกแอปตอนนี้
5. ใส่ PIN เพื่อปลดล็อก
6. ทดสอบ Restore Backup แล้วดู Preview ก่อนนำเข้า
