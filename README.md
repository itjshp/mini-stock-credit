# Khaikhong v2.2.4

เวอร์ชันนี้แก้ปุ่มรายละเอียดซ้ำ และเพิ่มระบบราคาขายส่ง

## สิ่งที่แก้

1. ปุ่มรายละเอียดซ้ำในหน้าลูกค้า
   - จากเดิมแสดง `รายละเอียด` ซ้ำ 2 ปุ่ม
   - แก้ให้เหลือปุ่มเดียว

2. เพิ่มราคาขายส่งในสินค้า
   - หน้า สินค้า มีช่อง `ราคาขายปลีก`
   - เพิ่มช่อง `ราคาขายส่ง`
   - ตารางสินค้าแสดงทั้งราคาปลีกและราคาส่ง

3. ขายให้ลูกค้าขายส่งใช้ราคาส่ง
   - ถ้าเลือกลูกค้าประเภท `ขายส่ง`
   - ระบบจะใช้ `ราคาขายส่ง` ตอนเพิ่มสินค้าเข้าบิล
   - ถ้าไม่ได้ตั้งราคาส่ง ระบบจะ fallback ใช้ราคาปลีก

4. เปลี่ยนลูกค้าระหว่างทำบิล
   - ถ้าเปลี่ยนลูกค้าเป็นขายส่ง/ขายปลีก ระบบจะรีเฟรชราคาสินค้าในบิลปัจจุบันให้ตรงกับประเภทลูกค้า

5. Import CSV สินค้า
   - รองรับคอลัมน์ `ราคาขายปลีก`
   - รองรับคอลัมน์ `ราคาขายส่ง`

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
