# Khaikhong v2.3.0

เวอร์ชันนี้เพิ่มระบบ FIFO Cost Lots เพื่อให้ต้นทุนและกำไรแม่นขึ้นเมื่อราคาทุนสินค้าเปลี่ยน

## สิ่งที่เพิ่ม

1. FIFO Cost Lots
   - ซื้อเข้า / Import สต็อกเริ่มต้น / ปรับเพิ่มสต็อก จะสร้างล็อตต้นทุน
   - ขายสินค้า ระบบตัดล็อตเก่าก่อนอัตโนมัติ
   - ไม่ต้องเลือกล็อตตอนขาย เพื่อให้ขายของเร็วเหมือนเดิม

2. คำนวณต้นทุนขายจากล็อตจริง
   - ถ้าขาย 8 ชิ้น แต่ล็อตเก่ามี 6 ชิ้น ระบบจะตัด:
     - 6 ชิ้นจากล็อตเก่า
     - 2 ชิ้นจากล็อตถัดไป
   - กำไรของบิลจะอ้างอิงต้นทุนจริงจาก FIFO

3. รายละเอียดสินค้า
   - แสดงล็อต FIFO คงเหลือ
   - เห็นวันที่รับเข้า จำนวนรับเข้า จำนวนคงเหลือ และทุนต่อหน่วยของแต่ละล็อต

4. รายละเอียดบิล
   - แสดง FIFO breakdown ในรายการสินค้า
   - เห็นว่าสินค้าในบิลถูกตัดจากล็อตไหน จำนวนเท่าไร และต้นทุนเท่าไร

5. ตรวจ/ซ่อม FIFO
   - เพิ่มปุ่มในหน้า เพิ่มเติม
   - ใช้สร้างล็อตใหม่จากประวัติเดิม และคำนวณต้นทุน/กำไรใหม่ทั้งระบบ
   - เหมาะหลังอัปเดตจากเวอร์ชันเก่า หรือหลังแก้ไขซื้อเข้า/ปรับสต็อก

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำหลังอัปเดต

1. ไปที่ เพิ่มเติม > ตรวจ/ซ่อม FIFO
2. กดตรวจ/ซ่อม FIFO 1 ครั้ง
3. ไปที่สินค้า > รายละเอียดสินค้า เพื่อดูล็อตคงเหลือ
4. ทดลองขายสินค้าที่มีหลายล็อตต้นทุน
5. เปิดรายละเอียดบิลเพื่อตรวจ FIFO breakdown
