# Khaikhong v2.0.5

เวอร์ชันนี้เพิ่มระบบรับเงินลูกหนี้แบบตัดบิล

## สิ่งที่เพิ่ม

1. รับเงินโดยเลือกบิล
   - เลือกลูกค้าแล้วระบบจะแสดงบิลเครดิตที่ยังค้าง
   - เลือกบิลที่ต้องการรับเงิน
   - รับเงินเต็มบิลหรือบางส่วนได้

2. อัปเดตสถานะบิลอัตโนมัติ
   - ถ้าจ่ายบางส่วน: สถานะ partial
   - ถ้าจ่ายครบ: สถานะ paid
   - ยอดค้างของบิลลดลงตามเงินที่รับ

3. ประวัติรับเงินผูกกับบิล
   - เห็นว่ารับเงินจากบิลไหน
   - กดดูรายละเอียดบิลจากรายการรับเงินได้

4. สมุดบัญชีลูกค้าชัดขึ้น
   - ขายเครดิตแสดงยอดบิล
   - รับเงินแสดงรายการลดหนี้
   - ยอดค้างคำนวณจากบิลจริง

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
