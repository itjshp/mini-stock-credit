# Khaikhong v2.3.18

เวอร์ชันนี้เพิ่ม Activity Log / Audit Trail

## สิ่งที่เพิ่ม

1. หน้า ประวัติการทำรายการ
   - อยู่ที่ เพิ่มเติม > ระบบ / ตั้งค่า / ความปลอดภัย > ประวัติการทำรายการ
   - ใช้ดูว่าใครทำอะไร เมื่อไร

2. บันทึกผู้ใช้งานที่ทำรายการ
   ระบบจะบันทึก:
   - ชื่อผู้ใช้งาน
   - บทบาท
   - วันที่และเวลา
   - ประเภทการทำรายการ
   - รายละเอียด
   - เลขบิลหรือรายการอ้างอิง
   - ยอดเงินที่เกี่ยวข้อง ถ้ามี

3. รายการที่บันทึก
   - ขายบิล
   - ยกเลิกบิล
   - ลบบิลถาวร
   - รับคืนสินค้า
   - รับเงินลูกหนี้
   - เพิ่ม/แก้สินค้า
   - เพิ่ม/แก้ลูกค้า
   - ซื้อเข้า
   - ปรับสต็อก
   - ตรวจนับสต็อก
   - ปิดรอบ / ปลดล็อก
   - Backup / Restore
   - จัดการผู้ใช้งาน

4. ค้นหาและกรอง
   - ค้นหาข้อความ
   - กรองผู้ใช้งาน
   - กรองประเภท
   - กรองวันที่
   - ปุ่ม วันนี้ / 7 วัน

5. Export / Copy
   - Export CSV
   - คัดลอกสรุป
   - ล้างเฉพาะ Log TEST

## หมายเหตุ

Activity Log เป็น Local-first เช่นเดียวกับข้อมูลอื่น ๆ ถ้า Restore Backup ก็จะ Restore Log ตามไฟล์ Backup นั้นด้วย

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. อัปโหลดไฟล์ทั้งหมดทับของเดิม
3. Commit changes
4. รอ GitHub Pages Deploy
5. เปิดแอปแล้วกด Ctrl+F5
