# Khaikhong PWA

เวอร์ชัน v1.0 — Stable MVP + Built-in Guide

สิ่งที่เพิ่ม/ปรับ:
- เพิ่มหน้า `คู่มือใช้งาน` ในเมนูเพิ่มเติม
- เพิ่มคำแนะนำสั้นในหน้าขายของ
- Flow หลักชัดขึ้น: เพิ่มสินค้า → ซื้อเข้า → ขายของ → รับเงิน/ดูยอดค้าง → Backup
- เพิ่มคำเตือน Backup ในหน้า Backup
- ชื่อไฟล์ Backup เปลี่ยนเป็น `khaikhong-backup-YYYY-MM-DD.json`
- ยังปิด Upgrade / Demo / Pro ไว้ก่อน เพื่อโฟกัสให้ระบบใช้งานจริงนิ่งก่อน
- ยังคงฟีเจอร์เดิม: ขายหลายสินค้าในบิล, Number Pad, ลูกค้า, ลูกหนี้, รายงาน, Backup

## วิธีอัปเดต GitHub Pages

1. Export Backup JSON จากแอปเดิมก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่ เพราะมี cache

## แนวทางใช้งานจริง

เริ่มจากสินค้า 3-5 รายการก่อน แล้วทดสอบซื้อเข้า ขายสด ขายเครดิต รับเงิน และ Backup
เมื่อข้อมูลตรงและใช้งานง่ายแล้ว ค่อยขยายข้อมูลจริงทั้งหมด
