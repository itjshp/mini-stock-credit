# Khaikhong v2.0.8

เวอร์ชันนี้เพิ่ม Backup Safety และ Import CSV

## สิ่งที่เพิ่ม

1. Backup Safety
   - หน้า Backup แสดงสถานะ Backup ล่าสุดชัดขึ้น
   - เตือนถ้ายังไม่เคย Backup
   - เตือนถ้า Backup ล่าสุดเกิน 24 ชั่วโมง

2. Import สินค้า CSV
   - ดาวน์โหลดไฟล์ตัวอย่างสินค้าได้
   - Import สินค้าจาก CSV ได้
   - ถ้าชื่อสินค้าซ้ำ จะอัปเดตราคา/หน่วย/ขั้นต่ำ
   - ถ้าไม่ซ้ำ จะเพิ่มสินค้าใหม่

3. Import ลูกค้า CSV
   - ดาวน์โหลดไฟล์ตัวอย่างลูกค้าได้
   - Import ลูกค้าจาก CSV ได้
   - ถ้าชื่อลูกค้าซ้ำ จะอัปเดตข้อมูล
   - ถ้าไม่ซ้ำ จะเพิ่มลูกค้าใหม่

## คอลัมน์ CSV สินค้า

ชื่อสินค้า, หน่วย, ราคาขาย, สต็อกขั้นต่ำ, หมายเหตุ

## คอลัมน์ CSV ลูกค้า

ชื่อลูกค้า, ประเภท, เบอร์โทร, วงเงินเครดิต, เครดิตกี่วัน, หมายเหตุ

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
