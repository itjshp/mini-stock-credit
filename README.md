# Khaikhong v2.3.3

เวอร์ชันนี้แก้ปัญหาปุ่มรายละเอียดสินค้า

## สิ่งที่แก้

1. ปุ่ม รายละเอียด ในหน้าสินค้า
   - แก้กรณีกดแล้วไม่เปิดหน้า Product Detail
   - สาเหตุคือหน้า Product Detail มีตัวแปรผิดชื่อในส่วนประวัติสต็อก ทำให้ JavaScript หยุดทำงาน

2. ประวัติสต็อกในรายละเอียดสินค้า
   - รองรับ purchase / adjust_in / adjust_out / cost_adjust / sale_return / sale_cancel
   - แสดงจำนวนและทุนได้ปลอดภัยขึ้น

3. เพิ่มตัวกัน error ตอนเปิดรายละเอียดสินค้า
   - ถ้าเกิด error อีก ระบบจะแสดงข้อความในหน้าแทนที่จะดูเหมือนกดแล้วไม่เกิดอะไร

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำหลังอัปเดต

1. ไปที่ สินค้า
2. กด รายละเอียด
3. ตรวจหัวข้อ Lot FIFO และประวัติสต็อก
