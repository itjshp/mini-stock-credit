# Khaikhong v2.2.3

เวอร์ชันนี้เพิ่มรายละเอียดลูกค้าและประวัติบิลรายลูกค้า

## สิ่งที่เพิ่ม

1. หน้า รายละเอียดลูกค้า
   - กดจากหน้าลูกค้า > รายละเอียด
   - ดูยอดซื้อรวม
   - ดูกำไรรวม
   - ดูยอดรับเงิน
   - ดูยอดค้าง
   - ดูจำนวนบิล
   - ดูบิลเครดิตที่ยังค้าง

2. ประวัติบิลของลูกค้า
   - แสดงบิลทั้งหมดของลูกค้าคนนั้น
   - กด ดูบิล เพื่อดูสินค้าในบิลนั้นว่าซื้ออะไรบ้าง
   - กด คัดลอก เพื่อคัดลอกข้อความบิล

3. ประวัติรับเงินของลูกค้า
   - แสดงรายการรับเงิน
   - ถ้าผูกกับบิล สามารถกดดูบิลได้

4. ปุ่มลัด
   - แก้ไขลูกค้า
   - สมุดบัญชี
   - รับเงิน

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
