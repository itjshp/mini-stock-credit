# Khaikhong v2.3.20

เวอร์ชันนี้ปรับ UX ของ Excel Legacy Import ให้เข้าใจง่ายขึ้น

## สิ่งที่ปรับ

1. Preview ชัดขึ้น
   - แสดงโหมด Import ว่าเป็น:
     - ตั้งต้นสินค้า/ลูกค้า
     - หรือนำเข้าพร้อมบิล
   - แสดงจำนวนสินค้า ลูกค้า บิล มูลค่าสต็อก และยอดขาย

2. อธิบายกรณีบิลเป็น 0
   - ถ้าไม่พบจำนวนขายในคอลัมน์ลูกค้า/เงินสด ระบบจะแจ้งว่า:
     “รอบนี้ยังไม่สร้างบิล”
   - พร้อมคำแนะนำว่าต้องกรอกอะไรใน Excel ถึงจะสร้างบิลได้

3. แสดงกลุ่มที่ตรวจพบ
   - เงินสด
   - เครดิต/ลูกค้าขายส่งจากหัวคอลัมน์ เช่น ยอดขายส่ง / แนน

4. เตือนวันที่ไม่ใช่รูปแบบมาตรฐาน
   - ถ้าวันที่ใน Excel เป็นตัวเลขแปลก ๆ ระบบจะแจ้งว่าใช้วันที่ปัจจุบันแทน
   - แนะนำให้ใช้วันที่แบบ 2026-07-22 หรือ 22/07/2026

5. ข้อความยืนยัน Import ชัดขึ้น
   - บอกก่อนว่ารอบนี้จะสร้างบิลหรือไม่
   - ถ้าไม่มีบิล จะบอกว่าเป็นการนำเข้าเฉพาะสินค้า/ลูกค้า/สต็อกเริ่มต้น

## วิธีใช้งาน

1. ไปที่ Backup
2. เลือกไฟล์ Excel เดิม
3. ดู Preview
4. ถ้าบิลเป็น 0 แต่ตั้งใจแค่นำเข้าสินค้า/สต็อก ให้กดยืนยันได้
5. ถ้าต้องการสร้างบิล ให้กลับไปกรอกจำนวนขายใน Excel ก่อน
