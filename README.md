# Khaikhong v2.0.7

เวอร์ชันนี้แก้บัคสำคัญที่ทำให้ปุ่มบันทึกสินค้าไม่ทำงาน

## สาเหตุบัค

ใน v2.0.6 JavaScript เรียกช่อง `paymentBill` แต่ใน HTML ไม่มีช่องนี้จริง ทำให้สคริปต์หยุดทำงานกลางทาง และทำให้ระบบฐานข้อมูลไม่เปิดสมบูรณ์ ปุ่มบันทึกสินค้าเลยกดแล้วไม่เกิดอะไรขึ้น

## สิ่งที่แก้

- เพิ่มช่อง `บิลที่รับเงิน` ในหน้า `รับเงิน`
- ป้องกัน JavaScript พังถ้าเจอ HTML เก่าใน cache
- ปรับ Service Worker cache เป็น v2.0.7
- ตรวจ JavaScript syntax แล้ว

## วิธีอัปเดต

1. แตกไฟล์ zip
2. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
3. Commit changes
4. รอ GitHub Pages deploy 1-3 นาที
5. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
6. ถ้ายังมีปัญหา ให้ล้าง cache ของเว็บนี้แล้วเปิดใหม่
