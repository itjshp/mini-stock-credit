# Khaikhong v2.1.5

เวอร์ชันนี้เพิ่ม Low Stock Center / สินค้าใกล้หมด

## สิ่งที่เพิ่ม

1. หน้า สินค้าใกล้หมด
   - อยู่ในเมนู เพิ่มเติม > สินค้าใกล้หมด
   - แสดงสินค้าที่สต็อกเหลือน้อยกว่าหรือเท่ากับขั้นต่ำ

2. ปุ่มลัดจากสินค้าใกล้หมด
   - รายละเอียดสินค้า
   - ซื้อเข้า
   - ปรับสต็อก

3. คัดลอกรายการสินค้าใกล้หมด
   - ใช้ส่งแชทหรือแจ้งคนซื้อของได้

4. พิมพ์รายการสินค้าใกล้หมด
   - ใช้ตรวจสต็อกหรือเตรียมซื้อเข้า

5. หน้า สรุป
   - เพิ่มกล่องแจ้งเตือนสินค้าใกล้หมดแบบย่อ

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
