# Khaikhong v2.2.9

เวอร์ชันนี้เพิ่ม Beta Ready Pack เพื่อเตรียมให้ร้านจริงทดลองใช้งาน

## สิ่งที่เพิ่ม

1. หน้า เริ่มต้นใช้งาน / Beta Ready
   - อยู่ในเมนู เพิ่มเติม > เริ่มต้นใช้งาน
   - อธิบายสถานะ Beta และการใช้แบบ Local-first

2. Checklist ความพร้อม
   - ตั้งค่าร้านแล้วหรือยัง
   - มีสินค้าแล้วหรือยัง
   - มีสต็อกแล้วหรือยัง
   - มีลูกค้าแล้วหรือยัง
   - เคย Backup แล้วหรือยัง
   - เคยทดสอบขายแล้วหรือยัง

3. เริ่มใช้งาน 5 ขั้นตอน
   - ตั้งค่าร้าน
   - เพิ่มสินค้า / Import CSV
   - ใส่สต็อกเริ่มต้น / ซื้อเข้า
   - เพิ่มลูกค้า
   - ทดลองขายและ Backup

4. Backup Reminder
   - แสดงสถานะ Backup ล่าสุด
   - เตือนถ้ายังไม่เคย Backup
   - เตือนถ้า Backup ล่าสุดเกิน 24 ชั่วโมง

5. Feedback / แจ้งปัญหา
   - เลือกหน้าที่เจอปัญหา
   - เลือกประเภท Feedback
   - เขียนรายละเอียด
   - คัดลอกข้อความ Feedback พร้อม Diagnostic

6. Diagnostic / ข้อมูลระบบ
   - เวอร์ชัน
   - จำนวนสินค้า
   - จำนวนลูกค้า
   - จำนวนบิล
   - Backup ล่าสุด
   - ขนาดหน้าจอ
   - Browser/User Agent

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำก่อนส่งให้ร้านทดลอง

1. ไปที่ เพิ่มเติม > เริ่มต้นใช้งาน
2. ดู Checklist ให้ครบ
3. Export Backup
4. ให้ร้านทดลองตามขั้นตอนในหน้า Beta Ready
5. ถ้าเจอปัญหา ให้กดคัดลอก Feedback ส่งกลับมา
