# Khaikhong v2.2.2

เวอร์ชันนี้แก้เรื่องทุน/กำไร และ Error รายละเอียดสินค้า

## สิ่งที่แก้

1. แก้ Error รายละเอียดสินค้า
   - เพิ่มหน้า `รายละเอียดสินค้า` กลับมาให้ครบ
   - แก้ข้อความแจ้งเตือนผิดที่ขึ้นว่าให้ update index.html
   - กดปุ่มรายละเอียดสินค้าได้ถูกต้อง

2. ป้องกันทุนเฉลี่ยเพี้ยนเมื่อมีสต็อกติดลบจากข้อมูลเก่า
   - ถ้ามีข้อมูลเก่าที่ทำให้สต็อกติดลบ ระบบจะไม่เอาจำนวนติดลบไปถ่วงทุนเฉลี่ยตอนซื้อเข้า

3. เพิ่มการปรับทุนเฉลี่ย
   - ไปที่ เพิ่มเติม > ปรับสต็อก
   - เลือกประเภท `ปรับทุนเฉลี่ย`
   - ใส่ทุนใหม่โดยไม่เปลี่ยนจำนวนสต็อก

4. เพิ่มระบบตรวจ/ซ่อมทุน
   - อยู่ใน เพิ่มเติม > ทดสอบระบบ > ตรวจ/ซ่อมทุน
   - คำนวณต้นทุนขายและกำไรบิลใหม่จากประวัติซื้อเข้า/ปรับทุน
   - เหมาะเมื่อเคยใส่ทุนผิดแล้วแก้ย้อนหลัง

5. หลังแก้ไข/ลบซื้อเข้า หรือปรับสต็อก ระบบจะคำนวณทุนและกำไรใหม่ให้

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำหลังอัปเดต

1. ไปที่ เพิ่มเติม > ทดสอบระบบ
2. กด `ตรวจ/ซ่อมทุน`
3. ไปที่ รายงาน เพื่อตรวจว่าทุน/กำไรกลับมาถูกต้อง
