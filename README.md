# Khaikhong v2.3.5

เวอร์ชันนี้แก้บัคหน้า ปิดรอบ / ล็อกข้อมูลย้อนหลัง

## สิ่งที่แก้

1. สถานะปิดรอบไม่แสดง
   - ใน v2.3.4 ระบบล็อกข้อมูลจริงแล้ว
   - แต่หน้า UI ไม่ได้เรียก renderClosePeriod ใน renderAll
   - ทำให้สถานะแสดงว่า “ยังไม่ล็อก” ทั้งที่ระบบกันรายการย้อนหลังแล้ว

2. ประวัติการปิดรอบไม่แสดง
   - แก้ให้ประวัติการปิดรอบแสดงทันที
   - ถ้าเคยปิดรอบไว้แล้วก่อนอัปเดต จะเห็นรายการเดิมหลังอัปเดต

3. ปุ่มปลดล็อกไม่เจอ
   - ปุ่มปลดล็อกอยู่ในประวัติการปิดรอบ
   - เมื่อประวัติไม่แสดง ปุ่มจึงไม่เห็น
   - รอบนี้แก้ให้แสดงแล้ว

4. เพิ่มปุ่ม รีเฟรชสถานะ
   - อยู่ข้างปุ่มบันทึกปิดรอบ
   - ใช้ดึงสถานะปิดรอบล่าสุดและแสดงผลใหม่

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## หลังอัปเดต

1. ไปที่ เพิ่มเติม > ปิดรอบ / ล็อกย้อนหลัง
2. ระบบควรแสดงว่า ล็อกถึงวันที่ 2026-07-22
3. ในประวัติการปิดรอบควรเห็น CP-20260722-0001
4. จะมีปุ่ม ปลดล็อก ในแถวประวัตินั้น

ไม่ต้องปิดรอบใหม่ ถ้าเคยปิดไว้แล้ว ข้อมูลรอบเดิมยังอยู่ครับ
