# Khaikhong v2.3.4

เวอร์ชันนี้เพิ่มระบบปิดรอบ / ล็อกข้อมูลย้อนหลัง

## สิ่งที่เพิ่ม

1. หน้า ปิดรอบ / ล็อกข้อมูลย้อนหลัง
   - อยู่ที่ เพิ่มเติม > ปิดรอบ / ล็อกย้อนหลัง
   - เลือกวันที่ที่ต้องการล็อกได้
   - เลือกประเภท: รายวัน / รายเดือน / กำหนดเอง

2. สรุปยอดก่อนปิดรอบ
   - จำนวนบิล
   - ยอดขาย
   - ต้นทุน
   - กำไร
   - ยอดค้าง
   - รับเงินลูกหนี้
   - ซื้อเข้า
   - คืนสินค้า

3. ล็อกข้อมูลย้อนหลัง
   หลังปิดรอบ ระบบจะไม่ให้แก้ไขข้อมูลในวันที่ปิดรอบแล้ว เช่น:
   - เพิ่มบิลย้อนหลัง
   - ยกเลิกบิล
   - ลบบิลถาวร
   - คืนสินค้าจากบิลเก่า
   - แก้/ลบซื้อเข้า
   - แก้/ลบรับเงิน
   - แก้/ลบปรับสต็อก
   - ตรวจนับย้อนหลัง

4. ประวัติการปิดรอบ
   - แสดงรอบที่ปิดแล้ว
   - แสดงยอดสรุปตอนปิดรอบ
   - ปลดล็อกได้โดยต้องพิมพ์เลขรอบเพื่อยืนยัน

## วิธีใช้งาน

1. Backup ข้อมูลก่อน
2. ไปที่ เพิ่มเติม > ปิดรอบ / ล็อกย้อนหลัง
3. เลือกวันที่ เช่น วันที่ปิดยอดวันนี้
4. ตรวจยอดสรุป
5. กด บันทึกปิดรอบ
6. หลังจากนั้นข้อมูลวันที่นั้นและก่อนหน้านั้นจะถูกล็อก

## วิธีปลดล็อก

1. ไปที่ประวัติการปิดรอบ
2. กด ปลดล็อก
3. พิมพ์เลขรอบ เช่น CP-20260722-0001
4. ใส่เหตุผล
5. ยืนยันปลดล็อก

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำให้ทดสอบ

- ปิดรอบถึงวันนี้
- ลองเพิ่มบิลย้อนหลังในวันที่ล็อกแล้ว
- ลองยกเลิกบิลวันที่ล็อกแล้ว
- ลองแก้ซื้อเข้า/รับเงิน/ปรับสต็อกวันที่ล็อกแล้ว
- ปลดล็อก แล้วลองแก้ไขอีกครั้ง
