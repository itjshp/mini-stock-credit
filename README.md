# Khaikhong v2.2.6

เวอร์ชันนี้เพิ่มหมวดหมู่สินค้า

## สิ่งที่เพิ่ม

1. หมวดหมู่สินค้า
   - เพิ่มช่อง `หมวดหมู่` ในหน้าสินค้า
   - เช่น อาหารแช่แข็ง, เครื่องดื่ม, ของใช้, อุปกรณ์ช่าง

2. กรองตามหมวดหมู่
   - หน้า ขายของ มีตัวกรองหมวดหมู่
   - หน้า สินค้า มีตัวกรองหมวดหมู่

3. แสดงหมวดหมู่ในหลายจุด
   - การ์ดสินค้าในหน้าขาย
   - ตารางสินค้า
   - รายละเอียดสินค้า
   - สินค้าใกล้หมด

4. Import CSV รองรับหมวดหมู่
   - เพิ่มคอลัมน์ `หมวดหมู่`

## CSV สินค้า

คอลัมน์ที่รองรับ:

ชื่อสินค้า, หน่วย, หมวดหมู่, ราคาขายปลีก, ราคาขายส่ง, สต็อกเริ่มต้น, ทุนเริ่มต้น, สต็อกขั้นต่ำ, หมายเหตุ

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## จุดที่ควรทดสอบ

- เพิ่มสินค้าใหม่พร้อมหมวดหมู่
- แก้ไขหมวดหมู่สินค้าเดิม
- กรองสินค้าในหน้าขาย
- กรองสินค้าในหน้าสินค้า
- Import CSV ที่มีหมวดหมู่
