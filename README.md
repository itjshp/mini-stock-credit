# Khaikhong v2.3.16

เวอร์ชันนี้แก้ปุ่มเมนูย่อยในหน้า เพิ่มเติม กดแล้วไม่ทำงาน

## สิ่งที่แก้

1. เมนูย่อยที่สร้างด้วย JavaScript กดแล้วไม่เข้าเมนู
   - เช่น ผู้ใช้งาน / สิทธิ์
   - สาเหตุ: ปุ่มถูกสร้างหลังจากระบบผูก event ตอนโหลดหน้าเสร็จแล้ว

2. เพิ่ม Event Delegation
   - ต่อไปเมนูย่อยที่สร้างทีหลังจะกดเข้าได้
   - ใช้ได้กับทุกเมนูในหน้า เพิ่มเติม

3. เพิ่ม fallback onclick
   - ปุ่ม dynamic menu จะมี onclick ติดไว้ด้วย
   - ช่วยให้กดได้แน่นขึ้นบน Browser/PWA

## วิธีอัปเดต

4. ต้องเข้าไปที่หน้าผู้ใช้งาน / สิทธิ์ ได้
