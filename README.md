# Khaikhong v2.1.1

เวอร์ชันนี้เพิ่มใบเสร็จ / คัดลอกข้อความบิล

## สิ่งที่เพิ่ม

1. ใบเสร็จในหน้ารายละเอียดบิล
   - แสดงชื่อร้านจากหน้า Settings
   - แสดงเลขบิล วันที่ ลูกค้า รายการสินค้า ยอดรวม รับเงิน และยอดค้าง

2. คัดลอกข้อความบิล
   - กดคัดลอกบิลแล้วนำไปส่ง LINE / Messenger / แชทลูกค้าได้

3. พิมพ์บิล
   - กดพิมพ์บิลจากหน้ารายละเอียดบิล
   - ใช้ browser print dialog

4. ปุ่มคัดลอกจากรายงาน
   - ในหน้ารายงานสามารถคัดลอกข้อความบิลได้ทันที

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
