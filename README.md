# Khaikhong v2.1.2

เวอร์ชันนี้แก้บัคจาก v2.1.1 ที่กด `ดูบิล` แล้วไม่เกิดอะไรขึ้น

## สาเหตุ

v2.1.1 มีปุ่มและฟังก์ชันสำหรับ `ดูบิล / คัดลอกบิล / พิมพ์บิล` แล้ว แต่ในไฟล์ HTML ไม่มีหน้า `<section id="billDetail">` จริง ทำให้กดแล้วระบบสลับไปหน้าที่ไม่มีอยู่

## สิ่งที่แก้

- เพิ่มหน้า `รายละเอียดบิล` ให้ครบ
- กด `ดูบิล` จากหน้า สรุป / รายงาน / ประวัติรับเงิน ได้
- แสดงใบเสร็จ / ข้อความบิล
- ปุ่ม `คัดลอกบิล`
- ปุ่ม `พิมพ์บิล`
- เพิ่มการแจ้งเตือนถ้าไฟล์ HTML ยังเก่าจาก cache
- อัปเดต Service Worker เป็น v2.1.2

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
7. ถ้ายังไม่เปลี่ยน ให้ล้าง cache ของเว็บนี้
