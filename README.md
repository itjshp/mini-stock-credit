# Khaikhong v2.3.6

เวอร์ชันนี้เพิ่มลูกหนี้ครบกำหนด และปรับหน้าเพิ่มเติมให้ใช้งานง่ายขึ้น

## สิ่งที่เพิ่ม

### 1. หน้า ลูกหนี้ครบกำหนด
อยู่ที่ เพิ่มเติม > ลูกหนี้ครบกำหนด

ระบบจะแสดงบิลเครดิตที่ยังค้าง พร้อม:
- ลูกค้า
- เลขบิล
- วันที่บิล
- วันครบกำหนด
- เกินกำหนดกี่วัน
- ยอดค้าง
- ปุ่มดูบิล
- ปุ่มรับเงิน
- ปุ่มคัดลอกข้อความแจ้งยอด

### 2. คำนวณครบกำหนดอัตโนมัติ
ระบบใช้เครดิตกี่วันจากข้อมูลลูกค้า เช่น:
- เครดิต 0 วัน = ครบกำหนดวันเดียวกับวันที่บิล
- เครดิต 7 วัน = วันที่บิล + 7 วัน
- เครดิต 30 วัน = วันที่บิล + 30 วัน

### 3. แยกสถานะลูกหนี้
- เกินกำหนด
- ครบกำหนดวันนี้
- ใกล้ครบกำหนด
- ยังไม่ครบกำหนด

### 4. คัดลอกข้อความแจ้งยอด
ใช้ส่งให้ลูกค้าได้ทันที เช่น แจ้งยอดค้างบิล ยอดค้าง วันครบกำหนด และสถานะเกินกำหนด

### 5. Export CSV ลูกหนี้
Export รายการลูกหนี้ตามตัวกรองที่เลือกอยู่

### 6. ปรับหน้า เพิ่มเติม
จากเมนูยาว ๆ เปลี่ยนเป็นหมวดหมู่:
- ใช้บ่อย
- ขาย/เงิน
- สต็อก
- รายงาน
- ระบบ

ยังมีช่องค้นหาเมนูเหมือนเดิม แต่ใช้งานง่ายขึ้นบน iPad/Mobile

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำให้ทดสอบ

1. สร้างลูกค้าที่มีเครดิตกี่วัน
2. ขายเครดิต
3. ไปที่ เพิ่มเติม > ลูกหนี้ครบกำหนด
4. ตรวจวันครบกำหนดและสถานะ
5. กดคัดลอกแจ้งยอด
6. กดรับเงินจากบิลค้าง
