# Khaikhong v2.0.0

Khaikhong v2.0.0 เป็นระบบใหม่แยกจาก v1.x โดยออกแบบข้อมูลใหม่ให้รองรับการใช้งานจริงมากขึ้น

## แนวคิดหลัก

- ขายเป็นบิลจริง (`bills`)
- รายการสินค้าในบิลแยกเป็น `bill_items`
- สต็อกทุกอย่างมาจาก `stock_movements`
- ลูกหนี้มาจากบิลเครดิตและรายการรับเงิน
- ยกเลิกบิลแทนการลบทิ้ง
- Backup/Restore เป็น JSON

## ฟีเจอร์ใน v2.0.0

- ขายหลายสินค้าในบิลเดียว
- เลขบิล `KH-000001`
- ขายเงินสด / เครดิต
- ยกเลิกบิลและคืนสต็อก
- เพิ่มสินค้า / แก้ไขสินค้า
- ซื้อเข้า
- เพิ่มลูกค้า / แก้ไขลูกค้า
- รับเงินลูกหนี้
- ยอดค้างลูกค้า
- สรุปวันนี้ / เดือนนี้
- รายงานบิล
- Export CSV
- Backup / Restore v2
- คู่มือใช้งานในแอป

## หมายเหตุสำคัญ

v2 ใช้ฐานข้อมูล IndexedDB ใหม่ชื่อ `khaikhong-v2-db` จึงไม่ทับข้อมูล v1.x โดยตรง
