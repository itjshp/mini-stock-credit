# Khaikhong v2.3.2

เวอร์ชันนี้เพิ่มระบบตรวจนับสต็อกจริง / Stock Count

## สิ่งที่เพิ่ม

1. หน้า ตรวจนับสต็อก
   - อยู่ที่ เพิ่มเติม > ตรวจนับสต็อก
   - ใช้กรอกจำนวนที่นับจริง เทียบกับยอดในระบบ

2. คำนวณผลต่างอัตโนมัติ
   - ระบบแสดงว่าต้องปรับเพิ่มหรือปรับลดกี่ชิ้น
   - แสดงมูลค่าผลต่างตามทุน FIFO เฉลี่ยคงเหลือ

3. บันทึกตรวจนับแล้วสร้างรายการปรับสต็อก
   - ถ้านับจริงมากกว่าระบบ = สร้าง adjust_in
   - ถ้านับจริงน้อยกว่าระบบ = สร้าง adjust_out
   - แล้วคำนวณ FIFO ใหม่ให้อัตโนมัติ

4. ประวัติการตรวจนับ
   - ดูรอบตรวจนับย้อนหลังได้
   - ดูรายละเอียดสินค้าแต่ละรายการได้
   - ลบ/ย้อนรายการตรวจนับได้ โดยระบบจะลบ movement ที่เกี่ยวข้องและคำนวณ FIFO ใหม่

5. ใช้งานร่วมกับ FIFO
   - ปรับลดจะตัดล็อต FIFO ตามลำดับ
   - ปรับเพิ่มจะสร้างล็อตใหม่ด้วยทุน FIFO เฉลี่ยคงเหลือของสินค้านั้น

## วิธีใช้งาน

1. ไปที่ เพิ่มเติม > ตรวจนับสต็อก
2. เลือกหมวดหมู่หรือค้นหาสินค้า
3. กรอกจำนวนที่นับจริง
4. ตรวจผลต่าง
5. กด บันทึกตรวจนับ
6. ระบบจะสร้างรายการปรับสต็อกและคำนวณ FIFO ใหม่

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## แนะนำให้ทดสอบ

- กรอกยอดนับจริงเท่ากับระบบ
- กรอกยอดมากกว่าระบบ
- กรอกยอดน้อยกว่าระบบ
- ตรวจว่าสต็อกเปลี่ยนถูกต้อง
- เปิดรายละเอียดสินค้าเพื่อตรวจ FIFO Lot
- ลบ/ย้อนรายการตรวจนับ แล้วตรวจว่าสต็อกกลับถูกต้อง
