# Khaikhong v2.2.1

เวอร์ชันนี้ปรับ UI ของระบบจริงให้ไปทางแบบ Concept รูป Pastel ที่เลือกไว้

## สิ่งที่ปรับ

1. Header / Brand
   - เพิ่มมาสคอตโลโก้
   - ปรับหัวเว็บให้ดูน่ารักและเป็นแอปมากขึ้น
   - เพิ่ม bubble ข้อความแอปจัดการร้านค้า

2. Theme ใหม่
   - Teal / Mint / Cream / Peach / Pastel
   - การ์ดโค้งมนขึ้น
   - เงานุ่มขึ้น
   - ปุ่มและสถานะดูเป็น Product มากขึ้น

3. เมนู
   - ปรับแท็บหลักให้มีไอคอน
   - Bottom Navigation แสดงสำหรับ iPad/Mobile

4. หน้าใช้งาน
   - ปรับ Card, Product Tile, Bill Card, KPI, More Menu ให้ไปทางเดียวกัน
   - ปรับ Empty State บางจุดให้น่ารักและเข้าใจง่ายขึ้น

## หมายเหตุ

เวอร์ชันนี้เน้น UI/UX เป็นหลัก ไม่เปลี่ยนฐานข้อมูล ไม่ล้างข้อมูลเดิม

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
