# Khaikhong v2.0.9

เวอร์ชันนี้เพิ่มหน้าตั้งค่า

## สิ่งที่เพิ่ม

1. หน้า ตั้งค่า
   - อยู่ในหน้า เพิ่มเติม > ตั้งค่า

2. ตั้งค่าชื่อร้าน / ชื่อระบบ
   - เปลี่ยนชื่อที่แสดงบนหัวเว็บได้

3. ตั้งค่าข้อความใต้ชื่อระบบ
   - เปลี่ยนคำโปรยใต้ชื่อระบบได้

4. ตั้งค่าเลขบิล
   - ตั้งคำนำหน้าเลขบิล เช่น KH, SALE, SHOP
   - ตั้งเลขบิลถัดไปได้
   - ดูตัวอย่างเลขบิลก่อนบันทึก

5. เปิด/ปิด POS Number Pad
   - ถ้าใช้ iPad/มือถือ แนะนำเปิด
   - ถ้าใช้คอมและคีย์บอร์ดจริง อาจปิดได้

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
