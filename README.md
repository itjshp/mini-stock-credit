# Khaikhong v2.3.17

เวอร์ชันนี้ปรับระบบผู้ใช้งานใหม่ ให้เริ่มต้นเป็นเจ้าของร้าน และสร้างผู้ใช้/ติ๊กสิทธิ์เองได้

## สิ่งที่แก้

1. ปัญหาเปลี่ยนเป็น Manager แล้วกลับไป Owner ยาก
   - ตอนเริ่มใช้งาน ระบบจะบังคับกลับเป็นเจ้าของร้านก่อน
   - หน้า ผู้ใช้งาน / สิทธิ์ จะไม่ถูกซ่อน เพื่อให้เปลี่ยนกลับได้เสมอ

2. เพิ่มระบบสร้างผู้ใช้งาน
   - สร้างชื่อผู้ใช้งานเองได้
   - เลือกบทบาทเริ่มต้น
   - เปิด/ปิดผู้ใช้งานได้

3. เพิ่ม Permission Builder
   สามารถติ๊กสิทธิ์เองได้:
   - ขายของ
   - ลูกค้า / สมุดบัญชี
   - รับเงิน / ลูกหนี้
   - รายงาน / ค้นหาบิล
   - สินค้า / สต็อก
   - ระบบ / Backup / ตั้งค่า
   - เห็นต้นทุน / กำไร

4. เพิ่มรายชื่อผู้ใช้งาน
   - กด ใช้งาน เพื่อสลับผู้ใช้
   - กด แก้ไข เพื่อปรับสิทธิ์
   - เจ้าของร้านลบไม่ได้

## หมายเหตุ

ยังเป็นระบบผู้ใช้งานแบบ Local-first สำหรับ Beta
ยังไม่ใช่ระบบ Login Cloud จริง ถ้าต้องการปลอดภัยจริงในอนาคตควรทำ Server/Login แยก

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. อัปโหลดไฟล์ทั้งหมดทับของเดิม
3. Commit changes
4. รอ GitHub Pages Deploy
5. เปิดแอปแล้วกด Ctrl+F5
6. เข้า เพิ่มเติม > ระบบ / ตั้งค่า / ความปลอดภัย > ผู้ใช้งาน / สิทธิ์
