# Khaikhong v2.2.7

เวอร์ชันนี้เพิ่ม Bill Search Center / ค้นหาบิลย้อนหลัง

## สิ่งที่เพิ่ม

1. หน้า ค้นหาบิล
   - อยู่ในเมนู เพิ่มเติม > ค้นหาบิล
   - ใช้ค้นหาบิลย้อนหลังแบบเร็ว

2. ตัวกรองค้นหาบิล
   - วันที่เริ่ม / วันที่สิ้นสุด
   - ปุ่มเร็ว: วันนี้, เมื่อวาน, 7 วัน, เดือนนี้
   - ค้นหาเลขบิล / ลูกค้า / หมายเหตุ
   - ค้นหาสินค้าในบิล
   - กรองลูกค้า
   - กรองสถานะบิล
   - กรองประเภทชำระเงิน

3. สรุปผลค้นหา
   - จำนวนบิล
   - ยอดขายรวม
   - ต้นทุนรวม
   - กำไรรวม
   - ยอดเครดิตค้าง

4. การจัดการบิลจากผลค้นหา
   - ดูบิล
   - คัดลอกบิล
   - พิมพ์บิล
   - ยกเลิกบิล
   - ลบถาวรเฉพาะบิลที่ยกเลิกแล้ว

5. Export CSV เฉพาะผลค้นหา

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## จุดที่ควรทดสอบ

- ค้นหาจากวันที่
- ค้นหาจากเลขบิล
- ค้นหาจากชื่อลูกค้า
- ค้นหาจากสินค้าในบิล
- กดดูบิลจากผลค้นหา
- Export CSV จากผลค้นหา
