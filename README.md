# Khaikhong v2.2.0

เวอร์ชันนี้เริ่มชุด UI/UX Redesign เพื่อให้ดูเป็นแอปจริงมากขึ้น

## สิ่งที่เพิ่ม/ปรับ

1. Theme ใหม่
   - โทน Clean + น่ารักขึ้น
   - การ์ดและปุ่มโค้งมนขึ้น
   - เงาและพื้นหลังดูเป็นแอปมากขึ้น

2. Bottom Navigation
   - บนมือถือจะแสดงเมนูล่าง
   - ขาย / สินค้า / ลูกค้า / สรุป / เพิ่ม

3. หน้า เกี่ยวกับแอป
   - ข้อมูล Local-first
   - Privacy
   - คำแนะนำ Backup
   - เหมาะกับใคร

4. Empty State
   - ปรับบางจุดให้ดูเป็นมิตรขึ้น

5. ยังใช้ข้อมูลเดิม
   - ไม่เปลี่ยนฐานข้อมูล
   - ไม่ล้างข้อมูลเดิม

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
