# Khaikhong v2.1.3

เวอร์ชันนี้ปรับ UX ของใบเสร็จและการแชร์บิล

## สิ่งที่เพิ่ม/ปรับ

1. ใบเสร็จอ่านง่ายขึ้น
   - แสดงสถานะ ชำระแล้ว / เครดิต / ยกเลิก ชัดเจน
   - แสดงยอดรับเงินแล้วและยอดค้างเด่นขึ้น
   - ถ้าบิลถูกยกเลิก จะแสดงเหตุผลและเวลายกเลิกในใบเสร็จ

2. คัดลอกบิล 2 แบบ
   - คัดลอกเต็ม
   - คัดลอกสั้น

3. แชร์บิล
   - ถ้าอุปกรณ์รองรับ Web Share จะเปิดเมนูแชร์ของเครื่อง
   - ถ้าไม่รองรับ จะคัดลอกข้อความบิลให้แทน

4. พิมพ์บิล
   - ปรับหน้าพิมพ์ให้อ่านง่ายขึ้น
   - แสดงสถานะบิลในหน้าพิมพ์

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
