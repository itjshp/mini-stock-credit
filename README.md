# Khaikhong v2.2.5

เวอร์ชันนี้เพิ่มส่วนลด, Import ข้อมูลเริ่มต้น และลบบิลแบบปลอดภัย

## สิ่งที่เพิ่ม

### 1. ส่วนลด
- ส่วนลดต่อรายการสินค้าในบิล
- ส่วนลดท้ายบิล
- คำนวณยอดขายหลังหักส่วนลด
- คำนวณกำไรหลังหักส่วนลด
- ใบเสร็จ/ข้อความบิลแสดงส่วนลด

### 2. Import ข้อมูลเข้า
- เพิ่มหน้า Import ใน Backup
- Import สินค้า CSV
- Import ลูกค้า CSV
- Import สต็อกเริ่มต้น + ทุนเริ่มต้น
- ถ้ามีสต็อกเริ่มต้น ระบบจะสร้าง stock movement ประเภท `opening`

### 3. ลบถาวรเฉพาะบิลที่ยกเลิกแล้ว
- บิลปกติยังใช้ “ยกเลิกบิล” เพื่อความปลอดภัย
- บิลที่ยกเลิกแล้ว สามารถลบถาวรได้จากรายละเอียดบิลหรือรายงาน
- ต้องพิมพ์เลขบิลเพื่อยืนยัน
- ระบบจะลบ bill_items, stock_movements และ payments ที่ผูกกับบิลนั้น
- หลังลบ ระบบคำนวณสต็อก/ทุน/กำไรใหม่

## CSV สินค้า

คอลัมน์ที่รองรับ:

ชื่อสินค้า, หน่วย, ราคาขายปลีก, ราคาขายส่ง, สต็อกเริ่มต้น, ทุนเริ่มต้น, สต็อกขั้นต่ำ, หมายเหตุ

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## จุดที่ควรทดสอบ

- ขายสินค้าแบบไม่มีส่วนลด
- ขายสินค้าแบบลดต่อรายการ
- ขายสินค้าแบบลดท้ายบิล
- ขายเครดิตพร้อมส่วนลด
- ยกเลิกบิล
- ลบถาวรบิลที่ยกเลิกแล้ว
- Import สินค้าพร้อมสต็อกเริ่มต้น/ทุนเริ่มต้น
