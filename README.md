# Khaikhong v2.1.0

เวอร์ชันนี้เพิ่ม Test Center สำหรับทดสอบระบบอัตโนมัติ

## สิ่งที่เพิ่ม

1. หน้า ทดสอบระบบ
   - อยู่ในหน้า เพิ่มเติม > ทดสอบระบบ

2. Auto Test
   - สร้างสินค้า TEST
   - สร้างลูกค้า TEST
   - สร้างซื้อเข้า TEST
   - สร้างขายเงินสด TEST
   - สร้างขายเครดิต TEST
   - สร้างรับเงิน TEST
   - สร้างปรับสต็อก TEST
   - สร้างบิลยกเลิก TEST

3. ตรวจข้อมูลอัตโนมัติ
   - สินค้าไม่มีสต็อกติดลบ
   - สต็อกตรงกับ Stock Movements
   - ยอดบิลตรงกับรายการสินค้าในบิล
   - ยอดรับเงินและยอดค้างของบิลถูกต้อง
   - รายการรับเงินผูกกับบิล
   - บิลยกเลิกมีเหตุผล

4. ล้างข้อมูล TEST
   - ล้างเฉพาะข้อมูลที่ขึ้นต้นหรือมีหมายเหตุ `TEST-AUTO`
   - ไม่ลบข้อมูลจริงที่ไม่ใช่ TEST

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
