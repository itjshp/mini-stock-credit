# Mini Stock Credit PWA

เวอร์ชัน v0.7 — Multi-item Bill / POS Cart

ฟีเจอร์ใหม่:
- เพิ่มบิลปัจจุบัน / ตะกร้าขายในหน้า ขาย POS
- เพิ่มหลายสินค้าใน 1 บิลได้
- ปุ่ม + / - ปรับจำนวนในบิล
- บันทึกทั้งบิล โดยระบบสร้างรายการขายหลายรายการพร้อมเลขบิลเดียวกัน
- รองรับขายเงินสดและขายเครดิตจากทั้งบิล
- ระบบกระจายยอดรับเงินแล้วในกรณีเครดิตชำระบางส่วน
- คงฟีเจอร์ v0.6: สมุดลูกหนี้, ตัวกรองรายงาน, Demo/Pro, Number Pad

## วิธีอัปเดต GitHub Pages

1. Export Backup JSON จากแอปเดิมก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่ เพราะมี cache

## หมายเหตุ

ข้อมูลจริงเก็บใน Browser/เครื่องที่ใช้งานด้วย IndexedDB ไม่ได้เก็บบน GitHub
ควร Export Backup เป็นประจำ
