# Khaikhong PWA

เวอร์ชัน v0.8 — Rebrand + Easy POS UI

สิ่งที่เปลี่ยน:
- เปลี่ยนชื่อจาก Mini Stock Credit เป็น `Khaikhong`
- ปรับแนว UI เป็นแบบ 1: เรียบง่ายมาก ใช้งานเร็ว
- ตั้งหน้าเริ่มต้นเป็น `ขายของ`
- ลดเมนูหลักให้เหลือ 5 เมนู: ขายของ, สินค้า, ลูกค้า, สรุป, เพิ่มเติม
- ย้ายเมนูรองไปไว้ในหน้า `เพิ่มเติม`
- ปรับภาษาหน้าจอให้ง่ายขึ้น เช่น ขายของ, รับเงิน, ยอดค้าง
- เพิ่มขั้นตอนใช้งานบนหน้าขาย: 1 เลือกสินค้า → 2 ใส่บิล → 3 บันทึกขาย
- ปรับปุ่มบันทึกขายและใส่บิลให้เด่นขึ้น
- ยังคงฟีเจอร์เดิม: Cart หลายสินค้า, Number Pad, Demo/Pro, ลูกหนี้, รายงาน, Backup

## วิธีอัปเดต GitHub Pages

1. Export Backup JSON จากแอปเดิมก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่ เพราะมี cache
