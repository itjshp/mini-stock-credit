# Khaikhong v2.3.21

เวอร์ชันนี้ปรับ Excel Legacy Import ให้รองรับไฟล์ใช้งานจริง `เก็บยอด.xlsx`

## สิ่งที่เพิ่ม

1. อ่าน Excel หลาย Sheet
   - ระบบจะอ่านทุก Sheet ในไฟล์ ไม่ใช่เฉพาะ Sheet แรก

2. ตรวจจับ Sheet ได้ 2 รูปแบบ

   ### รูปแบบ A: เก็บยอดรายลูกค้า
   เช่น Sheet:
   - คุณก้อย-พ.ค.
   - ก.ค.69

   หัวคอลัมน์:
   - ชื่อ
   - แผนก / ที่จัดส่ง
   - รายการ
   - จำนวน
   - ราคา/ชิ้น
   - รวม

   ระบบจะแปลงเป็น:
   - ลูกค้า
   - สินค้า
   - บิลเครดิตย้อนหลัง
   - ไม่กระทบสต็อก เพราะไฟล์ไม่มีต้นทุน/FIFO รายบิล

   ### รูปแบบ B: สต็อก + ยอดขายแบบตารางกว้าง
   เช่น Sheet:
   - 7

   หัวคอลัมน์:
   - ชื่อสินค้า
   - จำนวน
   - ทุน
   - ยอดขายปลีก
   - ยอดขายส่ง / ลูกค้า
   - คงเหลือ

   ระบบจะแปลงเป็น:
   - สินค้า
   - Opening Stock / FIFO Lot
   - ลูกค้าจากหัวคอลัมน์
   - บิลจากยอดขาย ถ้าพบจำนวนขาย

3. Preview แยกตาม Sheet
   - แสดงว่าแต่ละ Sheet เป็นชนิดไหน
   - แสดงจำนวนสินค้า ลูกค้า บิล
   - แจ้งเตือน Sheet ที่ข้าม

4. บิลจาก Sheet เก็บยอดไม่กระทบสต็อก
   เพื่อไม่ทำให้สต็อกติดลบหรือ FIFO เพี้ยนจากยอดย้อนหลังที่ไม่ได้ใช้เป็น stock movement จริง

## วิธีใช้งาน

1. ไปที่ Backup
2. เลือกไฟล์ Excel เดิม
3. เลือกไฟล์ `เก็บยอด.xlsx`
4. ดู Preview ว่าแต่ละ Sheet ถูกตรวจจับอย่างไร
5. กด ยืนยัน Import Excel

## หมายเหตุ

ถ้าต้องการให้ข้อมูลย้อนหลังมีผลกับสต็อกจริง ควรใช้ Sheet แบบสต็อก+ยอดขาย ไม่ใช่ Sheet เก็บยอดรายลูกค้า
