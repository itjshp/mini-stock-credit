# Khaikhong v2.0.2

เวอร์ชันนี้เพิ่มระบบรายละเอียดบิลและเหตุผลการยกเลิกบิล

## สิ่งที่เพิ่ม

1. รายละเอียดบิล
   - กดดูบิลจากบิลล่าสุดหรือรายงานได้
   - แสดงเลขบิล วันที่ ลูกค้า สถานะ
   - แสดงรายการสินค้าในบิล
   - แสดงยอดขาย ต้นทุน กำไร และยอดค้าง
   - แสดงรายละเอียดการชำระเงิน

2. ยกเลิกบิลพร้อมเหตุผล
   - ก่อนยกเลิกต้องกรอกเหตุผล
   - เก็บ `cancelReason`
   - เก็บ `cancelledAt`
   - คืนสต็อกให้อัตโนมัติ
   - บิลยังดูย้อนหลังได้ ไม่ลบทิ้ง

3. รายงาน
   - เพิ่มปุ่ม "ดูบิล"
   - บิลที่ยกเลิกจะแสดงสถานะยกเลิก
   - ยอดสรุปในรายงานไม่นับบิลที่ยกเลิก

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
