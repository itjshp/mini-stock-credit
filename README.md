# Khaikhong v2.0.3

เวอร์ชันนี้เพิ่มระบบปรับสต็อก

## สิ่งที่เพิ่ม

1. เมนู ปรับสต็อก
   - อยู่ในหน้า เพิ่มเติม > ปรับสต็อก

2. ปรับสต็อกเพิ่ม / ลด
   - ใช้เมื่อของเสีย ของหาย นับสต็อกแล้วไม่ตรง
   - ปรับเพิ่มสามารถใส่ทุนต่อหน่วย
   - ปรับลดจะตรวจว่าสต็อกพอหรือไม่

3. ประวัติปรับสต็อก
   - แก้ไขรายการปรับสต็อกได้
   - ลบรายการปรับสต็อกได้
   - หลังแก้ไข/ลบ ระบบคำนวณสต็อกและทุนเฉลี่ยใหม่

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
