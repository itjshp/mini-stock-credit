# Khaikhong v2.3.19

เวอร์ชันนี้เพิ่ม Excel Legacy Import สำหรับนำเข้าไฟล์ Excel เดิมของร้าน

## สิ่งที่เพิ่ม

1. Import ไฟล์ .xlsx แบบ Excel เดิม
   - อยู่ที่ Backup > Excel เดิม / Legacy Import
   - ไม่ต้อง Save as CSV ก่อน

2. อ่านโครงสร้างไฟล์เดิม
   รองรับหัวคอลัมน์ลักษณะ:
   - ชื่อสินค้า
   - วันที่
   - จำนวน
   - ราคา/หน่วย
   - ทุน
   - ยอดขายปลีก
   - ยอดขายส่ง / ชื่อลูกค้า
   - เงินสด
   - คงเหลือ

3. Preview ก่อน Import
   ระบบจะแสดง:
   - จำนวนสินค้า
   - จำนวนลูกค้า
   - จำนวนบิลที่จะสร้าง
   - มูลค่าสต็อกเริ่มต้น
   - ยอดขายจากไฟล์
   - คำเตือนถ้าข้อมูลไม่ตรง

4. แปลงข้อมูลเข้า Khaikhong
   - สร้าง/อัปเดตสินค้า
   - สร้าง opening stock/FIFO Lot
   - สร้างลูกค้าขายส่งจากหัวคอลัมน์
   - สร้างบิลเงินสด/เครดิตจากยอดขาย
   - บันทึก Activity Log

## วิธีใช้งาน

1. ไปที่ Backup
2. กด เลือกไฟล์ Excel เดิม
3. เลือกไฟล์ .xlsx
4. ดู Preview
5. กด ยืนยัน Import Excel

## หมายเหตุ

ไฟล์ Excel เดิมเป็นรูปแบบเฉพาะร้าน ถ้านำไฟล์จากที่อื่นมาใช้ หัวคอลัมน์อาจไม่ตรง ต้องปรับตัวอ่านเพิ่มอีกครั้ง
