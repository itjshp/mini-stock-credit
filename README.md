# Khaikhong PWA

เวอร์ชัน v0.9 — Clean MVP

สิ่งที่เปลี่ยน:
- ปิด Upgrade / Demo / Pro ออกจากหน้าหลักชั่วคราว
- ไม่จำกัดสินค้า ลูกค้า และรายการขายในช่วง MVP
- Export CSV ใช้งานได้โดยไม่ต้องปลดล็อก
- ซ่อนปุ่มขายรายการเดียว เพื่อลดความสับสน
- เน้น flow หลัก: เลือกสินค้า → เพิ่มลงบิล → บันทึกขาย
- ปรับปุ่มขายให้เด่นและกดง่ายขึ้น
- ยังคงฟีเจอร์เดิม: Cart หลายสินค้า, Number Pad, ลูกหนี้, รายงาน, Backup

## วิธีอัปเดต GitHub Pages

1. Export Backup JSON จากแอปเดิมก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่ เพราะมี cache

## แนวทางต่อไป

โฟกัสให้ระบบขายของใช้งานง่ายและเสถียรก่อน แล้วค่อยเปิด Upgrade / Pro ภายหลัง
