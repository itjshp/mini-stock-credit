# Khaikhong v2.1.4

เวอร์ชันนี้เพิ่มสรุปปิดยอดวันนี้

## สิ่งที่เพิ่ม

1. ปิดยอดวันนี้ ในหน้า สรุป
   - ยอดขายวันนี้
   - กำไรวันนี้
   - เงินสด/โอนที่ได้รับจากบิลวันนี้
   - เครดิตใหม่วันนี้
   - รับเงินลูกหนี้วันนี้
   - จำนวนบิลวันนี้

2. คัดลอกสรุปวันนี้
   - กดคัดลอกเพื่อนำไปส่งแชทหรือเก็บรายงาน

3. พิมพ์สรุปวันนี้
   - เปิดหน้าพิมพ์ของ Browser เพื่อพิมพ์สรุปปิดยอด

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
