# Khaikhong v2.3.15

เวอร์ชันนี้เอาโหมดซ่อนยอดเงินออก และเพิ่มระบบผู้ใช้งาน/สิทธิ์แบบ Local-first

## สิ่งที่เพิ่ม

### 1. ผู้ใช้งาน / สิทธิ์การเข้าถึง
อยู่ที่:
เพิ่มเติม > ระบบ / ตั้งค่า / ความปลอดภัย > ผู้ใช้งาน / สิทธิ์

บทบาทที่มี:
- เจ้าของร้าน
- ผู้จัดการ
- แคชเชียร์
- สต็อก

### 2. เจ้าของร้าน
เห็นทุกเมนูและทุกข้อมูล:
- ยอดขาย
- กำไร
- ต้นทุน
- Backup
- ปิดรอบ
- ตั้งค่า
- ตรวจ/ซ่อม FIFO

### 3. ผู้จัดการ
ใช้งานส่วนใหญ่ได้ แต่ไม่เน้นต้นทุนลึก:
- ขาย
- รับเงิน
- ลูกค้า
- รายงานพื้นฐาน
- สต็อก
- ตรวจนับ

### 4. แคชเชียร์
เน้นขายหน้าร้าน:
- ขายของ
- รับเงิน
- ค้นหาบิล
- ลูกค้าแบบจำกัด
- ไม่เห็นกำไร/ต้นทุน

### 5. สต็อก
เน้นจัดการสินค้า:
- สินค้า
- ซื้อเข้า
- สินค้าใกล้หมด
- ตรวจนับสต็อก
- ปรับสต็อก
- ไม่เห็นยอดขาย/กำไร

## หมายเหตุสำคัญ

ระบบนี้เป็นสิทธิ์แบบ Local-first สำหรับช่วง Beta ยังไม่ใช่ Login Cloud จริง
เหมาะสำหรับ:
- ลดเมนูที่ไม่เกี่ยวข้อง
- ลดโอกาสเห็นกำไร/ต้นทุน
- ทดสอบ workflow กับร้านจริง

ถ้าจะทำให้ปลอดภัยจริงในอนาคต ควรทำระบบ Login + Cloud + User Account แยกเครื่อง

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. อัปโหลดไฟล์ทั้งหมดทับของเดิม
3. Commit changes
4. รอ GitHub Pages Deploy
5. เปิดแอปแล้วกด Ctrl+F5
