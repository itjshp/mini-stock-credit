# Khaikhong v2.0.4

เวอร์ชันนี้แก้บัคหน้าปรับสต็อกที่กดแล้วเป็นหน้าว่าง

## สิ่งที่แก้

- เพิ่มหน้า `ปรับสต็อก` ให้แสดงผลจริง
- ปุ่มในหน้า `เพิ่มเติม > ปรับสต็อก` เปิดหน้าได้ถูกต้อง
- เพิ่ม/แก้ไข/ลบรายการปรับสต็อกได้
- ตรวจสต็อกก่อนปรับลด
- คำนวณสต็อกและทุนเฉลี่ยใหม่หลังบันทึก/แก้ไข/ลบ
- แก้โครงสร้าง JS ไม่ให้ซ้ำซ้อน

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
