# Khaikhong v2.0.6

เวอร์ชันนี้เพิ่มหน้ารายละเอียดสินค้าและประวัติสินค้า

## สิ่งที่เพิ่ม

1. รายละเอียดสินค้า
   - กดปุ่ม `รายละเอียด` ในหน้าสินค้า
   - ดูสต็อกคงเหลือ
   - ดูทุนเฉลี่ย
   - ดูราคาขาย
   - ดูสถานะใกล้หมด/ปกติ

2. สรุปยอดของสินค้า
   - จำนวนที่ขายไป
   - ยอดขายรวมของสินค้านั้น
   - กำไรรวมของสินค้านั้น
   - จำนวนบิลที่มีสินค้านี้

3. ประวัติสินค้า
   - ประวัติขายจากบิล
   - ประวัติซื้อเข้า
   - ประวัติปรับสต็อก
   - ประวัติคืนสต็อกจากการยกเลิกบิล

4. ปุ่มลัด
   - ซื้อเข้า จากหน้ารายละเอียดสินค้า
   - ปรับสต็อก จากหน้ารายละเอียดสินค้า
   - แก้ไขสินค้า

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
