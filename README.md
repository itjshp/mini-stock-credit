# Khaikhong v2.2.8

เวอร์ชันนี้เพิ่ม Customer Purchase History และปรับ UX หน้าเพิ่มเติม

## สิ่งที่เพิ่ม

1. ประวัติการซื้อของลูกค้า
   - อยู่ในหน้า รายละเอียดลูกค้า
   - กรองตามวันที่ได้
   - ค้นหาสินค้าในประวัติได้
   - เลือกมุมมองได้ 4 แบบ:
     - ภาพรวม
     - บิลที่ซื้อ
     - รายการที่ซื้อ
     - สรุปสินค้า

2. มุมมองบิลที่ซื้อ
   - เห็นบิลทั้งหมดของลูกค้าคนนั้น
   - กดดูบิลเพื่อดูรายการสินค้าในบิลได้
   - คัดลอกบิลได้

3. มุมมองรายการที่ซื้อ
   - เห็นรายการสินค้าทุกชิ้นจากทุกบิล
   - เห็นวันที่, เลขบิล, จำนวน, ราคา, ส่วนลด, รวม, กำไร

4. มุมมองสรุปสินค้า
   - รวมสินค้าที่ลูกค้าซื้อ
   - เห็นจำนวนรวม, ยอดขายรวม, กำไร, ซื้อครั้งล่าสุด

5. Export/Copy/Print
   - คัดลอกสรุปลูกค้า
   - พิมพ์ประวัติ
   - Export CSV เฉพาะลูกค้าคนนั้น

6. ปรับหน้า เพิ่มเติม
   - เพิ่มช่องค้นหาเมนู
   - ช่วยให้หาเมนูเร็วขึ้นบนมือถือ/iPad

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
