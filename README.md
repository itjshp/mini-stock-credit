# Khaikhong v2.3.1

เวอร์ชันนี้เพิ่มระบบคืนสินค้า / รับคืนบางรายการ ต่อจาก FIFO Cost Lots

## สิ่งที่เพิ่ม

1. คืนสินค้าเป็นรายรายการจากบิลเดิม
   - เปิดหน้า ดูบิล
   - ในรายการสินค้าแต่ละตัวจะมีปุ่ม `คืนสินค้า`
   - ระบุจำนวนที่คืนได้
   - ใส่เหตุผลการคืนสินค้า

2. คืนบางรายการได้ ไม่ต้องยกเลิกทั้งบิล
   - เช่น ขายไป 10 ชิ้น คืน 2 ชิ้น
   - ระบบจะลดเฉพาะยอดของ 2 ชิ้นที่คืน

3. คืนสต็อกกลับเข้าระบบ
   - ระบบสร้าง stock movement ประเภท `sale_return`
   - คืนกลับด้วยทุนของรายการขายเดิม
   - FIFO จะนำของคืนกลับมาเป็นล็อตใหม่พร้อมต้นทุนเดิม

4. ปรับยอดขาย/ต้นทุน/กำไรของบิล
   - บิลจะแสดงยอดคืนสินค้า
   - ยอดขายสุทธิจะลดลง
   - ต้นทุนสุทธิจะลดลง
   - กำไรจะคำนวณใหม่

5. ประวัติการคืนสินค้า
   - ในหน้า ดูบิล จะแสดงประวัติการคืนสินค้า
   - เห็นวันที่, สินค้า, จำนวน, เหตุผล และต้นทุนที่คืนเข้าสต็อก

6. ป้องกันยกเลิกบิลแล้วคืนสต็อกซ้ำ
   - ถ้าบิลเคยคืนสินค้าบางส่วนแล้ว
   - ตอนยกเลิกบิล ระบบจะคืนเฉพาะจำนวนที่เหลือเท่านั้น

## วิธีใช้งาน

1. ไปที่ รายงาน หรือ ค้นหาบิล
2. กด ดูบิล
3. ในรายการสินค้า กด คืนสินค้า
4. ใส่จำนวนที่ต้องการคืน
5. ใส่เหตุผล
6. ระบบจะคืนสต็อกและคำนวณยอดใหม่ให้อัตโนมัติ

## วิธีอัปเดต

1. Export Backup JSON ก่อน
2. แตกไฟล์ zip
3. อัปโหลดไฟล์ทั้งหมดทับของเดิมใน GitHub Repository
4. Commit changes
5. รอ GitHub Pages deploy 1-3 นาที
6. เปิดเว็บแล้วกด Ctrl+F5 หรือปิด/เปิด PWA ใหม่

## จุดที่ควรทดสอบ

- ขายสินค้า 1 บิล
- เปิดดูบิลแล้วคืนสินค้า 1 รายการบางส่วน
- ตรวจว่าสต็อกเพิ่มกลับ
- ตรวจว่ายอดขาย/ต้นทุน/กำไรของบิลลดลง
- คืนสินค้าครบทั้งรายการ
- ยกเลิกบิลที่เคยคืนบางส่วน แล้วเช็กว่าไม่คืนสต็อกซ้ำ
