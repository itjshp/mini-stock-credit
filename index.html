ล้างข้อมูลทั้งหมด

ใช้เฉพาะตอนเริ่มใหม่ แนะนำให้ Backup ก่อน

ทดสอบระบบ

สร้างข้อมูลทดสอบ ตรวจสูตรสำคัญ และล้างข้อมูล TEST ได้ในหน้าเดียว

คำเตือนก่อนทดสอบ

แนะนำให้ Export Backup ก่อนทดสอบ ข้อมูลทดสอบจะขึ้นต้นด้วย TEST- และสามารถล้างเฉพาะข้อมูลทดสอบได้

ผลการทดสอบ

ยังไม่ได้ทดสอบ
กด “สร้างข้อมูลทดสอบ + ตรวจระบบ” เพื่อเริ่ม ระบบจะสร้างสินค้า ลูกค้า ซื้อเข้า ขายสด ขายเครดิต รับเงิน ปรับสต็อก และยกเลิกบิลแบบ TEST

ข้อมูล TEST ที่ระบบใช้

ใช้สำหรับแยกข้อมูลทดสอบออกจากข้อมูลจริง

ตั้งค่า

ตัวอย่างเลขบิลถัดไป KH-000001

คำแนะนำ

คำนำหน้าเลขบิลใช้ตัวอักษรสั้น ๆ เช่น KH, SALE, SHOP เพื่อให้อ้างอิงบิลได้ง่าย
เลขบิลถัดไปถ้าตั้งเป็น 25 บิลต่อไปจะเป็น KH-000025
Number Padเหมาะกับ iPad/มือถือ ถ้าใช้คีย์บอร์ดคอมเป็นหลักสามารถปิดได้
