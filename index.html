Import ข้อมูลเริ่มต้น

สินค้า + สต็อกเริ่มต้น

รองรับ: ชื่อสินค้า, หน่วย, ราคาขายปลีก, ราคาขายส่ง, สต็อกเริ่มต้น, ทุนเริ่มต้น, สต็อกขั้นต่ำ, หมายเหตุ

ลูกค้า

รองรับ: ชื่อลูกค้า, ประเภท, เบอร์โทร, วงเงินเครดิต, เครดิตกี่วัน, หมายเหตุ

Excel เดิม / Legacy Import

รองรับไฟล์ .xlsx แบบที่ร้านเคยใช้งานจริง เช่น ชื่อสินค้า, จำนวน, ราคา/หน่วย, ทุน, ยอดขายส่ง/ลูกค้า และเงินสด

แนะนำ: ควร Export Backup ก่อน Import ทุกครั้ง ถ้ามีสต็อกเริ่มต้น ระบบจะสร้างรายการเคลื่อนไหวสต็อกประเภท opening ให้อัตโนมัติ

Backup สำคัญมากถ้าล้าง Browser หรือเปลี่ยนเครื่องโดยไม่ Backup ข้อมูลอาจหายได้
