Backup

ข้อมูลอยู่ในเครื่อง ควรสำรองข้อมูลเป็นประจำ

สำคัญ: ข้อมูลเก็บใน Browser/เครื่องที่ใช้งาน ไม่ได้อยู่บน GitHub
ควร Export Backup เป็นประจำ

Import ข้อมูลเริ่มต้น

นำเข้าสินค้า/ลูกค้าจาก CSV เหมาะกับย้ายจาก Excel หรือ Google Sheet

สินค้า + สต็อกเริ่มต้น

รองรับ: ชื่อสินค้า, หน่วย, ราคาขายปลีก, ราคาขายส่ง, สต็อกเริ่มต้น, ทุนเริ่มต้น, สต็อกขั้นต่ำ, หมายเหตุ

ลูกค้า

รองรับ: ชื่อลูกค้า, ประเภท, เบอร์โทร, วงเงินเครดิต, เครดิตกี่วัน, หมายเหตุ

แนะนำ: ควร Export Backup ก่อน Import ทุกครั้ง ถ้ามีสต็อกเริ่มต้น ระบบจะสร้างรายการเคลื่อนไหวสต็อกประเภท opening ให้อัตโนมัติ

ล้างข้อมูลทั้งหมด

ใช้เฉพาะตอนเริ่มใหม่ แนะนำให้ Backup ก่อน

ทดสอบระบบ

สร้างข้อมูลทดสอบ ตรวจสูตรสำคัญ และล้างข้อมูล TEST ได้ในหน้าเดียว

คำเตือนก่อนทดสอบ

แนะนำให้ Export Backup ก่อนทดสอบ ข้อมูลทดสอบจะขึ้นต้นด้วย TEST- และสามารถล้างเฉพาะข้อมูลทดสอบได้

ผลการทดสอบ

ยังไม่ได้ทดสอบ
กด “สร้างข้อมูลทดสอบ + ตรวจระบบ” เพื่อเริ่ม ระบบจะสร้างสินค้า ลูกค้า ซื้อเข้า ขายสด ขายเครดิต รับเงิน ปรับสต็อก และยกเลิกบิลแบบ TEST

ความเป็นส่วนตัว

ข้อมูลอยู่ในเครื่องคุณข้อมูลสินค้า ลูกค้า บิล ยอดขาย และลูกหนี้ เก็บใน Browser/อุปกรณ์ที่ใช้งาน
ผู้พัฒนาไม่ได้เห็นข้อมูลแอปนี้เป็น Local-first และไม่ได้ส่งข้อมูลไปยัง Server ของผู้พัฒนา
Backup สำคัญมากถ้าล้าง Browser หรือเปลี่ยนเครื่องโดยไม่ Backup ข้อมูลอาจหายได้

  4. Export Backup ทุกวันหลังใช้งานจริง
