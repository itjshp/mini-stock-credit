คู่มือใช้งาน Khaikhong

คู่มือสั้น ๆ สำหรับเริ่มใช้งานจริง ใช้เวลาอ่านประมาณ 3 นาที

1

เริ่มต้นครั้งแรก

  1. ไปเมนู สินค้า แล้วเพิ่มสินค้าก่อน
  2. ไป เพิ่มเติม > ซื้อเข้า เพื่อเพิ่มสต็อกและต้นทุน
  3. กลับมาหน้า ขายของ เพื่อเริ่มขาย
  4. กด Backup หลังกรอกข้อมูลจริง
2

วิธีขายของ

  1. ค้นหาสินค้า แล้วแตะสินค้า
  2. ใส่จำนวนและราคาขาย
  3. กด เพิ่มลงบิล
  4. ถ้ามีหลายสินค้า ให้เลือกเพิ่มต่อ
  5. กด บันทึกขาย
3

ขายเครดิต / ลูกค้าค้างจ่าย

  1. เพิ่มลูกค้าในเมนู ลูกค้า
  2. ตอนขาย ให้เลือกชำระแบบ เครดิต/ค้างชำระ
  3. เลือกชื่อลูกค้า
  4. ดูยอดค้างได้ที่ เพิ่มเติม > ยอดค้าง
  5. รับเงินได้ที่ เพิ่มเติม > รับเงิน
4

แก้ไข / ลบรายการผิด

  1. ไปที่ประวัติขาย / ซื้อเข้า / รับเงิน
  2. กด แก้ไข เพื่อปรับข้อมูล
  3. กด ลบ เมื่อต้องการลบรายการผิด
  4. ระบบจะคำนวณสต็อก กำไร และลูกหนี้ใหม่ให้อัตโนมัติ
5

Backup สำคัญมาก

ข้อมูลของแอปนี้เก็บในเครื่อง/Browser ที่ใช้งาน ไม่ได้เก็บบน GitHub

  1. กด เพิ่มเติม > Backup
  2. กด Export Backup JSON
  3. เก็บไฟล์ไว้ใน Google Drive / iCloud / Flash Drive
  4. ควร Backup ทุกวันหลังใช้งานจริง
6

ข้อแนะนำให้ใช้งานลื่น

  • อย่าล้างข้อมูล Browser ถ้ายังไม่ได้ Backup
  • ถ้าใช้หลายเครื่อง ข้อมูลจะไม่ sync กันเอง ต้อง Export/Import Backup
  • เริ่มใช้งานจริงจากสินค้า 3–5 รายการก่อน เพื่อทดสอบตัวเลข
  • ถ้าหน้าเว็บไม่อัปเดต ให้กด Ctrl+F5 หรือปิด/เปิด PWA ใหม่
